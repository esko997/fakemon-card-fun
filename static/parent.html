Tablet setup

  1. Install the local certificate on the tablet: Settings → Security → Encryption & credentials → Install a certificate → CA certificate. This removes the browser's security warning.
  2. Open this site in Chrome, then ⋮ → Add to Home screen.
  3. Optional: pin the app (Settings → Security → App pinning) so it stays on the card maker.
